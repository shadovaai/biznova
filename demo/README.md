# BizNova Public Demo

This folder contains a self-contained, static portfolio demo for BizNova.

## What it demonstrates

- customer-facing commerce experience
- product discovery and search
- product/inventory presentation
- operational dashboard concepts
- Nova AI operational briefing
- approval-oriented workflow design

## Safety boundary

All values and products shown in this demo are fictional sample data. The demo does not contain production credentials, customer information, proprietary prompts, private integrations, or production infrastructure.

Open `index.html` in a browser to view the demo locally.
